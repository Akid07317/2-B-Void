# 学术广泛筛查报告：分析与下一步

依据用户上传的 `deep-research-report (3).md` 全文。本轮阅读全部约838行，并对若干关键论文及遗漏项作定向联网核验；不是对全部候选、效应量或复现仓库的逐项认证。未修改正式代码和学习安排。

## 总判断

这份报告完成了有用的领域导览：内容表示、状态估计、测评、教学活动和排程不再混为一谈，也正确提醒预测准确与教学收益不同。但它尚不足以完成核心决策算法选型，尤其没有深入研究“在有限时间内选择下一项学习活动”的代表方法。

用途判断：适合定职责、形成阅读路线、排除不合适的全局掌握分；不适合作为已验证最优学习系统的设计证明。

## 最有价值的三项贡献

1. **量化先明确声称和证据。** 目录用于组织材料，可检验目标用于定义能力，独立作答和产物用于支持判断。覆盖、成本、独立表现、保持、迁移与项目产出分别保留。
2. **帮助强度也是决策。** 下一步可以是看示范、补步骤、尝试、给提示、独立题或新变式，并非永远推荐下一道题。该思想直接适用于刚开始的 NumPy/PyTorch 和不熟悉的数学技巧。
3. **不同模型解决不同问题。** BKT/PFA的局部反应预测、IRT/CAT的测量效率、记忆模型的复习日期、教学策略的活动选择、日历的容量与截止，应该有不同接口和验收。

报告引用的 pyKT 评估警示确有出处：原论文讨论了标签泄漏与若干深度知识追踪方法的有限改进。但那是特定基准和当时模型的结果，不能延伸为所有后续模型没有价值。[NeurIPS原文入口](https://proceedings.neurips.cc/paper_files/paper/2022/hash/75ca2b23d9794f02a92449af65a57556-Abstract-Datasets_and_Benchmarks.html)

## 广泛筛查仍有哪些缺口

### 1. 文献可追溯性在导出后不完整

本地文件含118处工具引用块，但没有普通HTTP链接，另有23处DOI字符串。原聊天中引用可能能打开；本地Markdown中的内部引用ID不能替代可移植书目。部分条目只是“某某系列”“某某路线”，缺精确题名、版本、链接和全文状态。

应补一张可导出的书目表：精确题名、年份、DOI/URL、出版状态、原文位置、访问范围、关键结论。约50项是论文、理论家族、数据集和仓库的混合候选，不能作为50份独立效果证据；报告本身对重复证据已有部分提醒。

### 2. 活动选择算法的调查最薄弱

报告给出了Bandit/RL/POMDP的概念、状态和奖励难题，却没有充分分析该方向代表论文的算法、样本、对照、结果与失败边界。

至少应补下面两条：

| 路线 | 为何与本任务直接相关 | 本轮核验范围与边界 |
| --- | --- | --- |
| RiARiT / ZPDES | 依据经验学习进展选择活动，用专家约束辅助探索；直接处理活动顺序 | 2015期刊摘要说明有模拟和约400名儿童的真实研究，任务是货币操作中的数分解；不是大学多课程长期验证。[JEDM原文](https://jedm.educationaldatamining.org/index.php/JEDM/article/view/JEDM111) |
| Faster Teaching via POMDP Planning | 在示例、测验和带反馈的问题之间决策，权衡教学、诊断和时间 | 原文含模拟与真人概念学习实验；部分策略优于简单对照，但不能说复杂策略总优于强信息量基线或能管理完整学期。[Wiley原文](https://onlinelibrary.wiley.com/doi/10.1111/cogs.12290)；另有[部分复现记录](https://rescience.github.io/bibliography/Bruckner_2020.html) |

这不推翻“真人、真实大学课程、长期迁移证据有限”的谨慎结论，却说明不能凭缺少调查就把整个方向只放成概念储备。下一步应核对学习进展的计算、探索规则、专家先验、动作成本、模型误设与比较基线。

### 3. 新近AI教育证据未完成应有核验

报告对Bastani等只留待追踪，也未深入处理Kestin等的大学课程试验。本轮已取得正式原文页：

- [Bastani等，PNAS 2025](https://www.pnas.org/doi/10.1073/pnas.2422633122)：高中数学现场试验中，无约束AI支持提高练习表现，却损害随后无工具考试表现；专门设计的提示减轻该负面结果，但不能说由此已证明带提示AI提高独立学习结果。
- [Kestin等，Scientific Reports 2025](https://www.nature.com/articles/s41598-025-97652-6)：大学物理随机比较中，专门设计的AI辅导在所测短期后测中表现更好；任务、教学条件与后测期限限定其外推，不能作为长期保持或全部学科的证明。

应对照研究教学结构、提示方式、比较条件和撤掉工具后的测验，不能把AI教育一概归为尚只有模拟的路线。报告没有声称完全不存在真人研究，但这部分检索不充分。

### 4. 数学证据应更贴近大学任务

报告较依赖经典一般记忆研究和中学交错研究，遗漏了已发表的2025数学专门元分析。公开摘要显示间隔练习的正向平均效应较稳健，而数学检索对重学的平均效应区间跨零，尚无一致优势的确证。它不能证明检索无用，但限制了从词汇到数学的推广。[Murray等原文摘要](https://link.springer.com/article/10.1007/s10648-025-10035-1)

报告的“示范→渐隐→独立→交错→迁移”可以作候选教学结构；把几组研究拼成一条箭头，不代表该完整固定顺序已在个人多科情境被验证。允许依据任务与先验返回前一步、跳过已会部分或做短诊断；竞赛必须全覆盖的材料约束另行保持。

## 四处工程推论需要修正

### 固定优先级同样包含价值判断

“截止/全覆盖→先修→复查→缺口→项目”虽然没有数值权重，仍是一套强优先级政策。当必修需求长期不空，项目会持续得不到时间，违背课业与项目并重。

应先让用户定义各目标的阶段预算及最低保留量，再在科目内部选活动；真不可行时显示缺口与取舍。无需一开始发明学习收益总分，但也不能宣称字典序天然客观或一定优于所有加权方案。

### 相同选择也可能节约成本

“建议与人工长期相同就没有价值”过强。同一任务若选择更快、少漏事、少冲突，仍有执行价值；要另测决策时间和维护成本。反过来，经常给出不同建议也不证明更好。

### 只看未执行的建议，不能证明学习收益

Shadow policy适合检查建议是否可行、合理、稳定以及与简单规则有何不同。用户没有执行某建议时，不能知道执行它后的反事实学习结果。“事后看起来合理”仍可能受结果偏见影响。

### 学习实验不能照搬可洗脱的交叉设计

学过的内容不会在下一轮恢复未学状态。报告虽提到carry-over，却仍需在具体协议中解决：使用可比的未学目标、分组和次序平衡、预先留出未见题、记录交叉接触。个人小样本首先用于发现操作失败与较大的效果信号，不能直接认证因果提分。

报告中的估时比例误差也应处理实际时间为0、未知、不完整日志和任务范围变化；否则短任务或漏记会扭曲统计。

## 对你的App应怎样取舍

| 层 | 当前值得吸收 | 尚不宜直接承诺 |
| --- | --- | --- |
| 目标与证据 | 轻量目标、材料引用、固定评分标准、首次/提示/重复标记 | 一个跨学科总掌握率 |
| 活动建议 | 根据明确卡点建议示范、补步骤、独立题、变式或复查 | 已找到个人最优教学政策 |
| 时间安排 | 真实时间窗、阶段预算、保护项目最低投入、统一容量检查 | 贪心没找到就视为数学无解 |
| 状态建模 | 原始证据先行；公开数据上的BKT/PFA、记忆模型实验 | 用个人几十条日志可靠拟合全部技能 |
| 研究实验 | RiARiT/ZPDES、POMDP的原论文与小任务复现 | 直接控制全部日程和学习活动 |

实际界面不需要展示这些模型名。例：某目标可显示“视频已看；首次独立题1/3；提示后完成；尚未做延迟变式”，随后给一项带理由、估时和来源的练习候选。用户挑选后再拖入时间段。这是从报告提炼的产品建议，不是已实现功能。

## 下一步应收敛到三个问题

1. **内容与题目如何对应？** 以一个竞赛专题和一个编程目标做claim–evidence–task样例，验证粒度和记录成本。
2. **如何决定下一项活动？** 深读RiARiT/ZPDES及POMDP，分别拆输入、状态、动作、奖励/成本、更新、冷启动、基线和真人验证；先复现小任务，不直接管全学期。
3. **如何评价教学支持？** 对照Bastani与Kestin的教学设计，定义无工具、未见题和延迟结果，避免只测有帮助时完成率。

报告可以作为第一轮地图保留。完成这三处定向工作后，才有足够依据判断哪条方法值得实现；不必再写一轮同范围、同深度的几十篇泛读清单。
