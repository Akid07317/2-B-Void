## V1.1主要修订

1. 剩余量变少后的锁块调整、独立保留时段与原子提交。
2. 工作量覆盖、待核实占位和任务状态拆分。
3. 活跃计时、已确认日志、运行尾部与未来预约的统一容量记账。
4. 自动保护集中确认、人工锁逐项授权。
5. 期限排序、补救队列、贪心基线与候选方案比较。
6. 时间推进导致的缓存/提案失效、局部阻塞处理。
7. 默认缓冲统一为显式启用20%；新增验收不继承原文PASS。
