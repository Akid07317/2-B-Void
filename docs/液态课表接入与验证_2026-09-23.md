# 0.3 液态课表接入与验证

2026-09-23。本轮接入实际 App，不是独立静态原型。正式数据库未读写；验证使用 `/tmp/liubai-glass-console-20260923.sqlite3`。

## 已实现

- 主控制台：所选日期的任务完成数、已记录投入、其中计时、待执行安排、可再安排时间；当前/下一项、当日分析和待排任务。
- 日/周课表：08:00 起的逐小时刻度，存在更早事件时扩展；半小时细线；每小时 120px，位置与高度反映真实时间。周视图在自己的容器中横向滚动。
- 起止时间可到分钟；鼠标移动、拖动底边、表单编辑、Alt+↑/↓ 一分钟移动、撤销、刷新恢复。短任务保留真实细条，通过底部文字条查看/编辑，并可从对应把手拖动。
- 任务悬停/键盘聚焦呈现玻璃表面和独立详情；指针可移入面板阅读，Esc 关闭；点击打开可编辑详情。触屏沿用点击与明确拖动把手。
- 中文保持本地思源宋体；英文/数字使用平台系统字体。控制台正文和任务标题放大，统计使用等宽数字，统一对齐与字号角色。
- 自有 SVG 图标统一比例，加入轻双色层次；记录入口由心电图改为柱状统计图，任务入口改为勾选清单。不引入整套外部图标依赖，未生成图片。
- 时长统一 `HH:MM:SS`；补记支持秒级起止；新记录区分 TIMER / MANUAL，旧记录不伪造来源。

## 数据与兼容边界

“当日任务”依据该日实际安排、投入记录和完成日期聚合；全局待排任务不自动算进当天。尚无独立的“仅加入今天而不指定时间”清单模型。

“待执行安排”是该日已安排但尚待执行/核实的预计投入，不是所有任务的全局剩余工时。未知执行或计时未结束时，可再安排量显示待核实，避免输出虚假的精确容量。纯计时仅包括带明确来源的新计时记录及运行计时；旧来源未知记录仍计入总投入。

基础网格改为 60 秒；自动排程时段策略与精度分离，仍保留 30 分钟常规最小块、60 分钟段上限、完整短尾和 15 分钟估计取整/缓冲档位。手动 MANUAL 时段可为 1 分钟。旧预约无需批量迁移；旧填充可继续核算。剩余估计减少导致末尾预约成为纯填充或负工时，会要求释放多余保护块，不能生成负工作量。

玻璃由 CSS 半透明、背景模糊、渐变高光和阴影实现，是 Web 玻璃风格，不是 Apple 原生折射实现。尊重减少动态与减少透明度设置。
