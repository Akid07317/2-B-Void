# 用户设计意见 · 2026-09-23

本轮先记录与调查，不修改 App，不直接生成图片。

## 用户明确提出

- 现有图标不够直观，也未体现理想的 UI 质感；希望像优质付费软件一样，低调、有美感，交互时有表现力。
- 调查 GPT Image 是否有必要参与 UI 资源制作，先判断用途再生成。
- 时间相关统计最好精确到秒。
- 时间表改成可拖动的课表式网格，按 08:00、09:00 等小时显示行，任务安排精确到分钟。
- 光标悬停任务时出现液态玻璃效果，并显示该任务的内容。

## 延续此前要求

- 中文使用思源宋体；英文采用 Apple 系统字体方案。
- 文字更大、排列工整、共享对齐线，删除非必要说明。
- 主控制台包含今天日程、今天任务分析、专注/投入时长统计、剩余时间。
- 先调查，再将文字排版、信息结构、图标与主控制台一起设计。

## 优先级与边界

本次课表式网格取代此前原型的日程行列表方向。具体图标体系、配色、动画参数和分钟吸附方案尚待调查，不应把研究建议当作已经得到用户确认的最终规格。秒级统计不能把估算时间包装成测量结果。
