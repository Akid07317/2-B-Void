# 已知问题与验收缺口

整理：2026-10-02。以下问题来自 2026-09-23 的本地独立评审复核；本次仓库整理没有修复业务逻辑，也没有重新运行该组反例。应在后续修复时补成断言正确结果的回归用例。原始评审包含个人资料，保留在本地。

| 问题 | 复核情况与下一步 |
| --- | --- |
| HOLD 恢复可能重复预留 | 旧占位与新剩余需求可能重复占用容量；反馈恢复后应重新判断旧块。 |
| 完成后补记实际投入 | 已完成任务无法补记历史投入；完成事实和实际日志应分别处理。 |
| 暂停计时封锁同日排程 | 暂停状态仍限制同日新安排；需要区分活动、暂停、结束和待核实状态。 |
| 缩减估时与受保护块冲突 | 应及时显示旧计划待处理并提供授权调整入口。 |
| 贪心排程漏掉可行方案 | 未找到方案不等于无解；保留 `NOT_PROVEN`，后续验证局部交换或连续空档策略。 |
| 时间窗口与课程转场 | 手动分钟排程已支持；每日可用窗口仍按整数小时，缺少教学周、日期例外和转场约束。 |
| 日志更正 | 暂无可追溯修订流程；真实投入与人工剩余量应分别处理。 |
| 旧响应导致状态回退 | 后端重试可返回原操作快照；前端乱序响应的后果仍需端到端验证。 |
| 编辑标题携带旧剩余量 | 表单仍有相关路径；需要字段差量和显式估时确认，浏览器用例待验证。 |

手动部分推进与自动全覆盖策略也有差异，需要明确欠量提示和人工选择的语义。学习作答证据到下一项活动、容量检查与重排的完整链路尚未实现。
