# 工作台界面重做 · 2026-09-22

本轮仅修改 planner/static/index.html、app.js、style.css；没有修改排程后端、数据库结构或正式用户数据。

## 界面变化

- 重新设计品牌、导航、顶部搜索、字号、配色、卡片与弹窗。
- 总览采用专注入口、三项真实指标、时间轴周视图和每日安排摘要。
- 日期范围切换为近7天/后7天，点击日期切换每日摘要。
- 日程块按时间对齐，点击可查看完整时间、锁定或记录执行。
- 任务页支持领域/归档筛选、名称与项目搜索、Cmd/Ctrl+K搜索快捷键。
- 任务按钮、计时、记录反馈、保存接口和确认流程继续使用原有业务逻辑。
- 小屏使用底部导航；日历内部独立横向滚动；尊重减少动画的系统偏好。
- 空数据时提供真实引导入口，没有向正式库添加展示任务或伪造统计。

## 本轮验证

- `node --check planner/static/app.js` 通过。
- 浏览器独立测试实例使用临时SQLite数据库；有4项测试任务和1项固定课程。
- 验证科研分类筛选只显示科研任务、输入“概率论”只显示匹配任务。
- 验证编辑弹窗保存、日历块详情、锁定、自动安排预览仍可操作。
- 验证日期范围切换后标题及所选日期摘要更新。
- 桌面1280宽和手机390×844布局截图检查；手机 document.scrollWidth=390、innerWidth=390，日历内容550宽在356宽容器内滚动，无页面横向溢出。
- 浏览器测试页控制台无error记录。
- 后端未改动，本轮不把此前29项测试描述为新UI自动测试；未新增镜像实现式测试。

日历当前用15分钟视觉网格，固定事件的精确起止时间仍显示在详情中。仍未增加拖拽排程功能。
