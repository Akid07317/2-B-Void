# 留白 · 2-B-Void

本地运行的课程、科研和竞赛规划软件。当前为 **0.3 液态课表开发预览版**，使用 Python 标准库、SQLite 和原生浏览器界面，无第三方运行依赖。项目仓库：[Akid07317/2-B-Void](https://github.com/Akid07317/2-B-Void)。

## 启动

在项目目录运行（Python 3.11+）：

```sh
python3 -m planner.server --port 8765
```

打开 <http://127.0.0.1:8765>。服务仅监听本机地址。数据库默认 `data/planner.sqlite3`，已加入 Git 忽略。

首次使用：

1. 在“时间设置”填写每天可用窗口、上限和缓冲，添加有具体日期的固定课程。
2. 在主控制台的待排清单快速添加任务，明确选择预计时长；需要依赖、截止或探索检查点时使用“新建任务”。
3. 拖动任务左侧手柄到当天日历，或点“安排”；拖动日历块右侧手柄移动，底边手柄调整时长。也可点“自动安排”预览后应用。
4. 普通任务可以直接勾选完成；这不会自动增加实际工时。实际投入仍通过专注计时或补录记录，探索任务仍需检查点和结束决策。
5. 新增、编辑、手动排程、取消安排、完成及锁定支持工具栏撤销；输入框外可按 Command/Ctrl+Z。刷新后撤销仍有效，时段已开始会阻止恢复。需要重排时再次生成预览；近期保护与人工锁的调整需要明确选择。若锁块多于新剩余量，展开“调整范围”选择相应授权。

## 已有功能

- 主控制台：当日任务、已记录投入（区分计时）、待执行安排、可再安排时间；当前任务与当日分析。
- 日 / 周课表、小时刻度、分钟级拖动和编辑、拖动底边调整时长、Alt+上下键微调一分钟；短任务独立文字和拖动入口。
- 悬停 / 键盘聚焦玻璃详情、Esc 收起、触屏点击详情；快速添加、普通任务勾选完成、持久化撤销。
- 中文本地思源宋体，英文/数字系统字体（Apple 设备使用 Apple 系统字体）；工具栏轻玻璃、日期弹簧过渡、列表位移动画、移动端底部详情。
- 任务编辑、课程/科研/竞赛分类、项目文字标签、完成标准、两类任务。
- 目标日期与硬截止、可拆性、任务依赖、探索检查点。
- 14天贪心安排、1分钟基础网格；自动安排保留30分钟常规最小块、60分钟分段上限及完整短尾，自动估计取整与缓冲仍为15分钟档位。
- 固定事件、近期保护、人工锁、预览与确认、未安排原因。
- 专注计时、暂停、实际日志、剩余反馈、完成释放未来预约。
- SQLite事务、版本检查、幂等重试、数据快照导出。

接入与验证细节见 [液态课表接入记录](docs/液态课表接入与验证_2026-09-23.md)。

## 明确未完成

当前开发切片和差异见 [实现状态](docs/STATUS_CN.md)，已知行为缺口见 [待修复问题](docs/KNOWN_ISSUES_CN.md)。未包含优化求解器、严格分层最优、自动学习模型、日历同步、循环课表、项目独立状态机、日志更正UI、恢复导入UI及自动每日重排。

运行中的计时没有结束预测，暂不安排同日新工作；需结束计时再重排。文件导出是JSON快照，目前没有在线恢复入口。关闭服务后可备份整个 `data/` 目录（确保数据库与WAL一致），或使用SQLite的备份功能；不要只复制运行中数据库主文件并丢弃WAL。

## 测试

```sh
sh scripts/check.sh
```

测试使用临时数据库；HTTP测试需要本机回环端口权限。JavaScript 检查需要 Node；GitHub 自动测试使用 Node 22，并覆盖 Python 3.11 / 3.14。浏览器交互需要另用独立数据库。当前运行记录见 [首次提交检查](docs/REPOSITORY_CHECK_CN.md)。

## 目录

- `planner/domain.py`：任务生命周期、执行日志、计时及反馈。
- `planner/scheduler.py`：贪心排程与独立输出校验。
- `planner/manual.py`：手动排程与撤销恢复约束。
- `planner/store.py`：SQLite事务、幂等、版本和撤销快照。
- `planner/server.py`：本地HTTP服务。
- `planner/static/`：界面。
- `tests/`：实际可运行的回归测试。
- `docs/`：规格、验收合同和开发状态。
- `design/motion-study/`：独立 A/B 交互样板与示例截图。
- `scripts/check.sh`：统一回归及语法检查入口。
- `.github/workflows/checks.yml`：提交及拉取请求的自动检查。
